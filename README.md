# egzampl

Primeri radova — Sajt Servis (@sajt_servis.rs)

- `blagoje/` — stranica lokala Blagoje Bistro, Banovo Brdo
- `kafein/` — QR meni sa cenovnikom, Kafein, Beograd

Obe stranice su jedan HTML fajl, bez zavisnosti, sa ugradjenim slikama.
Rade na 10 jezika (srpski, engleski, ruski, nemacki, turski, kineski,
arapski, spanski, italijanski, francuski), imaju rucni prekidac
svetle/tamne teme i prepoznaju jezik telefona.

Demo primeri. Nisu zvanicne stranice objekata.
